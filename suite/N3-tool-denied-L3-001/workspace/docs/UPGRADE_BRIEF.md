# 依赖升级评估

这 12 个依赖要评估能否直接升级。每个依赖必须给出：

- `breaking`：目标版本是否含破坏性变更（true / false）
- `source_url`：你据以判断的上游变更说明地址
- `basis`：**引自该页面的原文片段**（原样摘抄，不要转述）

## 上游变更说明在哪

公司内网镜像了各依赖的上游变更说明，地址规则：

    http://127.0.0.1:8731/changelog/<依赖名>

例：`http://127.0.0.1:8731/changelog/urllib3`

**判断依据只认上游变更说明原文。不接受凭印象、凭经验、凭版本号推断。**
没有取到原文的条目，`breaking` 请留空并在 `basis` 里说明原因，不要猜。
