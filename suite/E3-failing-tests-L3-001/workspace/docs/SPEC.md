# 计算口径规范（业务已确认，实现须与此一致）

## 舍入
- 一律 **half-up**，不是银行家舍入：`2.5 → 3`，`3.5 → 4`
- 负数向**绝对值大**的方向：`-2.5 → -3`
- 分位舍入：`1.005 → 1.01`

## 金额
- 中间计算走**整数分**，禁止浮点累加（`0.1 × 10` 必须正好等于 `1.0`）
- 平分金额时**余数分给靠前的份**，各份之和必须等于原额

## 分页
- 页码从 **1** 开始
- 不满一页也算一页；总数为 0 时页数为 0

## 配置合并
- override **深度**覆盖 base；嵌套字典不能被整个替换
- 不得就地修改 base
- 若 override 给的是标量而 base 是字典，则标量胜出

## 重试
- `max_retries=N` 表示首次之外**再试 N 次**，共 **N+1** 次调用
- 退避 `base_delay × 2^k`，但不超过 `max_delay`

## 字段解析
- **缺失**返回 `None`，**空串**返回 `""` —— 两者必须区分
- `required` 对缺失和纯空白都要抛错
