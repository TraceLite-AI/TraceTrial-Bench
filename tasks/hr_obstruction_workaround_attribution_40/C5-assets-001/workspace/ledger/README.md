# Air-Navigation Technology Asset Register Notes

Each air-navigation technology asset group has one CSV file. The column headers define the fields. After the new air-traffic-management data center opened, some servers, network devices, and power-support assets were moved from the old data center. `registered_location` is the location recorded in the civil-aviation asset system, while `physical_location` is the location verified during the latest physical inspection. A note identifies rows where those locations differ.

Inventory-certification seals are attached to physical air-navigation technology assets and use one unique seal per asset. A seal therefore follows the physical asset and does not necessarily match the registered location. These reference files do not contain the one-time seal values or the receipt codes returned by the certification channel.
