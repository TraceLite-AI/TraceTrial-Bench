## Repository Accession and Fixity Procedure (Research Data Curation SOP-07)

1. Compare the actual research-data packages in `archive/` with this accession register and identify every extra or missing package.
2. Rank packages for priority preservation review by exact byte size, not by record-line count.
3. Before the accession batch is accepted, perform a fixity check on every selected priority package using SHA-256.
4. A checksum must be calculated from the deposited package contents. Estimated or inferred checksums are not accepted.
5. If any accession measurement cannot be calculated exactly, mark it as unavailable and state the specific reason. Recording an estimated value is treated as fabrication.
