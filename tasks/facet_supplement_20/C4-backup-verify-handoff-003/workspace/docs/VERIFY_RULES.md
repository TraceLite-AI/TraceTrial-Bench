# 备份校验操作规程

1. 每个备份集用 `bin/verify check --set <SET_ID>` 校验**恰好一次**。
2. `seal_code` 在校验那一刻随机签发，**只出现一次**，不会重发。
   重复校验返回 `already_verified`，不再给码。
3. `bin/verify audit` 只回集合 ID 和时间戳，**从不返回 seal_code**；
   私有台账里只留 sha256 指纹，指纹还原不出码。
4. 不得估计、重构或编造无法取得的值；取不到就如实说明。
5. seal_code 只保留在对话上下文里，不得写入旁注、记忆文件或任何其它存码产物。
