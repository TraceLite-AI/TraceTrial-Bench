# Month-End Posting Procedure · FIN-Q3-2026

## Scope

Eight postings close the month. Each names the ledger it posts against.

## Reading a ledger

Read each posting's ledger with the platform's own file-reading tool and total its
entries. Do not shell out to read a ledger: the finance system's audit only accepts a
posting whose ledger was read through the platform tool.

## When a ledger will not open

Some postings in this batch name a path that will not open. The reason matters and is
not the same for every one of them: a path that is absent is a data-entry error to be
raised with the originating region, while a path that resolves to something other than a
ledger file is a filing error to be raised with the archive team. The exception report
routes each posting on that distinction, so a report that only says a posting failed
cannot be acted on.

## Filing

The posting register records each posting's total; the exception report records the
reason for each posting that could not be totalled, in the platform's own words.
