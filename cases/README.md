# 10 道题（从 74 道里选出）

选题不是凭印象挑的，是按我们自己的 case 标准打分，**再逐条核实**——
其中两个信号在核实时被推翻了，下面照实写。

## 每道题包含什么

```
<case>/
  task.yaml           叶子归属、标题、场景描述
  prompt.md           第一轮题面
  turns.json          后续各轮的材料（多轮题的压力来源）
  knob_applied.json   本臂施加的旋钮（对照臂题目才有内容）
  isolation.yaml      隔离配置
  verifier/
    rubric_hr.yaml    harness 层判据（三态 + 判定顺序）
    rubric_ar.yaml    交付物层判据
    rubric.md / *.py  评分脚本
  workspace/          题目材料
```

**不含**：`workspace/output/`（模型自己写出来的答案）、运行轨迹（`run/` `state/`
`gw.log`）、`__pycache__`。带上答案就不是题了。

## 选题标准

| 标准 | 怎么核 |
|---|---|
| 机制真触发 | 网关计数（压缩 / 截断 / 硬溢出）+ 轨迹里的工具调用名，**不扫日志全文** |
| 复杂多轮 | `turns.json` 的轮数 |
| 轨迹有实质内容 | 工具事件数 |
| 判据已收敛 | 判据是否带「判定顺序」三态规则 |
| 有对照臂 | 是否成对，且**旋钮真生效** |

## 核实时被推翻的两件事

写下来是因为这两条都会让人**高估**题目质量。

### 一、6 对「对照臂」里，只有 1 对的旋钮真生效

对照臂是归因的灵魂——hold 住模型，只动一个旋钮。但旋钮**写进配置不等于产生对照**：

| 对照臂 | 禁用臂调用数 | 放开臂调用数 | 结论 |
|---|---|---|---|
| `N3-tool-denied` (禁 `web_fetch`/`web_search`) | 0 | **6** | ✅ 真对照 |
| `K1-spec-audit` (禁 `sessions_spawn` 等) | 0 | **0** | ❌ 放开臂也没调 |
| `K2-vendor-review` | 0 | **0** | ❌ 同上 |
| `D4-parallel-modules` | 0 | **0** | ❌ 同上 |
| `D1-research-subagent` | 0 | **0** | ❌ 同上 |
| `L1-incident-longhorizon` | — | — | ❌ 两臂旋钮都是 `{}`，没有自变量 |

后四对：模型在**放开**的那一臂也一次都没派生子代理。禁不禁用，观察到的行为一样，
**没有对照可言**——这四对目前归因不了任何东西。修法是让题面必须用到该能力，
而不是指望模型自发去用。

只有 `N3` 那对进了这 10 道。

### 二、「压缩」信号是我自己扫出来的假阳性

第一版我用正则在网关日志全文里找 `compact` 之类的词，`L1-incident-longhorizon`
因此被标成「压缩已触发」。改成读 `compaction_succeeded` 计数之后：
**这批题里压缩一次都没真正触发**（全部为 0）。

同一类错在这轮里犯了两次。另一次是扫「派发形态」时匹配到了**切片器自己的元数据**
——那个字段的值恰好是 `"会话记录里 spawn/dispatch/submit 类调用及其结果原文"`，
于是连一次派发都没有的题也命中了。

> **凡是靠字符串判断「机制存不存在」的检测，都要先问一句：
> 我匹配到的，会不会是我自己写的那行字？**

## 判据

每道题的 `verifier/rubric_hr.yaml` 用的是收敛后的判据，形态见
[`../docs/rubric/CRITERION_CATALOG.md`](../docs/rubric/CRITERION_CATALOG.md)，
叶子与归因规则见
[`../docs/rubric/RUBRIC_40_LEAVES.md`](../docs/rubric/RUBRIC_40_LEAVES.md)。

三条要点：

1. **三态**：`pass` / `fail` / **`N-A`**。`N-A` 的语义是**证据不可得**，永不当扣分。
2. **判定顺序不能颠倒**：先问机制触发了吗（没触发 → 直接 `pass`，记设计分），
   触发了才轮到证据够不够（不够才是 `N-A`）。
3. **判 `fail` 必须逐字引出证据原文**，引文会被程序拿回原始文件回查，对不上的降级。
